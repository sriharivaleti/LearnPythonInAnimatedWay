# Learn Python in an Animated Way 🐍✨

An interactive, visual, step-by-step learning platform for Python concepts. Built **100% framework-free** using pure HTML5, CSS3, SVG, and Vanilla JavaScript—ready for instant one-click deployment on **GitHub Pages**.

---

## 🚀 Features

- **Split-Screen Interactive Layout**:
  - **Left Sidebar**: Structured curriculum tree tracking progress.
  - **Right Visual Stage**: Hardware-accelerated animated diagrams, flow pipelines, and memory visualizers.
- **Synchronized Triad**:
  1. **Visual Stage**: Animations update with dynamic micro-steps.
  2. **Synchronized Code Walker**: Line-by-line highlight corresponding to the active execution state.
  3. **Virtual Terminal**: Real-time simulated output and REPL inspector.
- **Granular Playback Controls**:
  - `Play / Pause` (`Space`)
  - `Step Forward` (`→`) and `Step Backward` (`←`)
  - `Reset` (`R`)
  - Playback speed multiplier (`0.5x`, `1.0x`, `1.5x`, `2.0x`)
  - Scrubbable timeline slider
- **Dark & Light Mode**: Persistent theme toggle via `localStorage`.

## 📚 Curriculum Included

### Session 1: Python Overview
1. **1.1 History of Python** (Guido van Rossum, 1991, Monty Python origin, ecosystem explosion)
2. **1.2 What is Python?** (High-level general-purpose language, `hello.py`, `.py` file runner)
3. **1.3 Why Learn Python?** (Beginner-friendly, industry demand, 500k+ packages, AI/ML leadership)
4. **1.4 Main Features of Python** (Easy syntax, High-level, Interpreted, Dynamically typed, OOP, Cross-platform, Large libraries, Open-source)
5. **1.5 Python Version** (Python 3 modern standard vs Python 2 deprecated, CLI version check)
6. **1.6 How Python Code Runs** (Source Code `.py` ➔ Bytecode `.pyc` ➔ Python Virtual Machine `PVM` ➔ Output)
7. **1.7 Compiler vs Interpreter Basics** (Dual-track architecture comparison & feature matrix)

## 🌐 Deploy to GitHub Pages in 30 Seconds

Because this project uses **zero frameworks, zero build steps, and zero external dependencies**:

1. Initialize git in this directory and commit:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Python Animated Learning Website"
   ```
2. Push to your GitHub repository:
   ```bash
   git remote add origin https://github.com/<your-username>/<your-repo-name>.git
   git branch -M main
   git push -u origin main
   ```
3. Enable GitHub Pages:
   - Go to your repository on GitHub.
   - Click **Settings** ➔ **Pages**.
   - Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
   - Select branch `main` and folder `/ (root)`.
   - Click **Save**.
4. Your site will be live at: `https://<your-username>.github.io/<your-repo-name>/`!
